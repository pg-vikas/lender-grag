# Replit Phase 3 Build Prompt — Gorilla Apps Mortgage Lender Super Admin

Build **Phase 3** of the **premium dark mode mortgage lender Super Admin platform** inside **Gorilla Apps**.

Phase 1 established the foundation:

* app shell
* dashboard
* CRM
* leads
* borrowers
* loan pipeline
* record detail pages
* global search
* quick create

Phase 2 added the execution layer:

* documents
* e sign
* conditions
* communications
* tasks
* deeper timeline integration

**Phase 3 is where Gorilla Apps becomes management grade.**
This phase should turn the platform from a strong operational system into a true executive control platform with automation, compliance oversight, pricing intelligence, reporting, branch management, and company level controls.

## Phase 3 goal

Build the management and intelligence layer with these modules:

* Automations
* Compliance
* Reports
* Pricing Desk
* Products / Programs
* Branches
* Team Management
* Executive Controls
* Settings expansion
* cross module analytics and alerting

This phase should make Gorilla Apps feel like a **serious mortgage company operating system** rather than a strong internal tool.

---

## Core objective for Phase 3

A lender using this build should now be able to:

* automate operational and sales follow ups
* monitor compliance exposure
* review executive performance data
* compare loan scenarios and pricing internally
* manage mortgage products and overlays
* evaluate branch performance
* manage team permissions and production visibility
* configure system level rules and templates
* make decisions from real reporting instead of guesswork

This phase is about control, leverage, and visibility.

---

## Visual direction

Continue the same premium design system from Phases 1 and 2.

### UI character

* dark mode first
* sharp
* dense but clean
* executive grade
* forceful hierarchy
* data heavy without looking messy
* premium control room energy

### Use color intentionally

* cyan / blue for active data and selected filters
* green for strong performance and compliant states
* amber for caution
* red for risk, exceptions, expirations, and compliance exposure
* Gorilla pink or magenta for core product actions and branded emphasis

### Avoid

* junk charts
* washed out enterprise clutter
* meaningless stats
* giant empty report pages
* lazy settings screens
* generic template admin look
