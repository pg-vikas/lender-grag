# Replit Phase 1 Build Prompt — Gorilla Apps Mortgage Lender Super Admin

Build **Phase 1** of a **premium dark mode mortgage lender Super Admin platform** inside **Gorilla Apps**.

This phase is focused on the **core operational foundation**.
Do not try to build the entire product yet.
Do Phase 1 cleanly and deeply.

## Phase 1 goal

Build the first usable version of the lender operating system with these modules only:

* App Shell
* Dashboard
* CRM
* Leads
* Borrowers
* Loan Pipeline
* Loan Detail Page
* Borrower Detail Page
* Global Search
* Quick Create
* Shared Drawers
* Mock Data Layer

This phase should feel like a real internal product already.

---

## Core product vision for Phase 1

The user should be able to:

* land on a serious lender command center
* see business performance instantly
* search for leads, borrowers, and loan files fast
* manage contacts and lead flow
* view a real pipeline by stage
* open individual loan files
* inspect borrower records
* understand how Gorilla Apps will become the lender’s central operating system

This is the foundation. It must be tight.

---

## Visual direction

Design Phase 1 like a **Pink Gorilla level premium admin platform**.

### Visual qualities

* dark mode first
* sharp typography
* strong grid system
* bold data cards
* dense but organized
* polished and premium
* operationally serious

### Palette

Use:

* black
* charcoal
* graphite
* near white text
* subtle magenta or Gorilla pink highlights
* muted cyan / blue for active UI
* green for positive metrics
* amber for warning
* red for risk

### Avoid

* template dashboard look
* soft startup SaaS styling
* overly rounded cards everywhere
* generic white admin UI
* playful design language
